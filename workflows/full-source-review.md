# Complete recordings and document review

When asked for a full transcript, register the entire recording as a deliverable. Do not substitute selected excerpts. Preserve original bytes, establish duration, and identify speakers/languages from supplied metadata or user testimony. Language and script may differ; preserve dialect uncertainty rather than forcing every segment into Hebrew. Ask the owner for speaker identity, not a summary the agent can extract itself.

Set source.kind to audio/video and extent to {unit:"seconds",total:DURATION}. Divide work into timestamp ranges with overlap where needed. Use an available authorized transcription tool; do not install models or upload audio to a new service without applicable authorization. This toolkit validates coverage but does not ship an ASR model. Preserve raw output and corrected transcript as separate files with recording ID, segment timestamps, speaker label/provenance, language, text and uncertainty. Segment keys must include recording ID and timestamps, never only an index reused across chunks.

Review overlaps, gaps, repetitive hallucinations and uncertain names. Reconcile corrections against the source audio. Record unintelligible passages explicitly, not fabricated words. Full review means covering every interval, not claiming every word is certain. Do not regenerate raw output when applying user corrections.

For documents (including certificates and marriage records), set kind:document and extent:{unit:"pages",total:COUNT}. Preserve original script, date/calendar text, exact page/region references, issuing context and uncertain readings. Review every page. A certificate may support a specific assertion without proving the entire family story. Compare against existing claims rather than overwriting them.

Coverage uses review.ranges with start, end and artifact. Ranges are half-open [start,end); pages/items use zero-based integer boundaries. Each range needs a real review artifact inside the workspace. Audio/video also needs review.transcript.raw and review.transcript.corrected pointing to separate files. The research gate rejects partial or missing coverage and hashes artifacts. Albums use kind:album, extent.unit:items. Unknown extent is unfinished review.

Persist prepared transcript outputs with `node src/cli/index.mjs transcript DIR INPUT.json`. Input has sourceId, raw, corrected and optional summary. Both transcripts have recordingId equal to the source ID, durationSeconds, and segments with unique id/start/end/text; language and speaker provenance may also be retained. Corrected segments preserve raw IDs/timestamps. Only corrected segments marked reviewStatus:reviewed or unintelligible count toward review coverage. This command preserves immutable raw JSON, versions prior corrections, and updates coverage. It does not run speech recognition or assert that machine output was listened to.

Extract proposed events into the shared event model, retaining source citations and uncertainty. Only reviewed conclusions become confirmed events. Tasks remain unfinished when material is blocked; the owner can explicitly approve proceeding with recorded gaps. Coverage validation proves recorded interval completeness, not transcript accuracy.
